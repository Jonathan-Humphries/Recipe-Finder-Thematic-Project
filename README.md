Instructions to run the website

1. Download docker if it is not already on your machine - https://www.docker.com/products/docker-desktop/
2. Download GitHub desktop if it is not already on your machine - https://desktop.github.com/download/
3. Open docker desktop on your machine
4. Open the Repo in GitHub Desktop either directly from GitHub desktop or via the GitHib website
5. Navigate to the GitHub folder in your file explorer and enter it
6. SHIFT + RIGHT CLICK on the folder titled 'Recipe-Finder-Thematic-Project' and click 'Open powershell window here' or 'Open in command prompt'
7. In the powershell line run the command  docker compose up --build
8. Navigate to http://localhost:13000/api/setup  in your browser of choice, this will initialise the DB so you can close it as soon as it is opened
9. Navigate to http://localhost:13000 in your browser of choice and the website will appear
